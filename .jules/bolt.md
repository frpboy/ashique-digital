## 2026-11-06 - Viewport-Aware Animation Loops in Multi-Instance Drei Views
**Learning:** In applications using `@react-three/drei`'s `<View>` components tied to a global Canvas (`ThreeSceneProvider`), any component defining a child mesh with `useFrame` will continuously trigger per-frame tick handlers and matrix calculations even when the component is off-screen. While isolated visual components like `GrowthSphere` and `BrokenNode` checked viewport visibility using `useInView`, multi-instance components like `ServiceIcon3D` (rendered 6 times in `ServicesGrid`) missed this check, compounding to hundreds of unnecessary frame callbacks per second while users view other sections.
**Action:** When creating or using `@react-three/drei` `<View>` or WebGL mesh components that execute `useFrame` animations, always gate child mesh rendering with `useInView` so that frame callbacks are unmounted and paused when off-screen.
